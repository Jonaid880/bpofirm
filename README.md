Australian security industry (CCTV monitoring, alarm response, AI surveillance,
construction/retail security, monitoring centres).

- [`seo-bot/README.md`](seo-bot/README.md) — module overview
- [`seo-bot/SETUP.md`](seo-bot/SETUP.md) — local install
- [`seo-bot/GITHUB_ACTIONS.md`](seo-bot/GITHUB_ACTIONS.md) — zero-server scheduled runs

Run `python seo-bot/run.py status` any time for a live state snapshot.
